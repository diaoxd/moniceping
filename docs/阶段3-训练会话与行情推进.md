# 阶段3：训练会话与行情推进

## 领域边界

随机候选模块负责选择股票和内部起点；训练会话模块接收选择结果，负责窗口、公开状态、推进、版本控制和回退。真实交易日期只存在于内部行情中。

## 已实现规则

- 起点是第一根待揭示的模拟日线；起点前必须存在200根日线，初始公开状态固定显示这200根。
- 模拟区间只能配置150或200根日线。
- 每次推进只公开一根新日线。
- 周线和月线只从当前已公开日线聚合，未完成周期随日线推进动态更新。
- 对外日、周、月K线均不包含真实日期，仅使用相对序号。
- 初始资金范围为10,000.00至10,000,000.00元，使用整数分。
- 推进和回退都检查 `expectedVersion`。
- 空仓时每次回退一根并恢复快照；有持仓返回 `ROLLBACK_BLOCKED_BY_POSITION`。
- 不能回退到模拟起点之前。
- 走完配置区间后会话进入 `finished`，禁止继续推进。
