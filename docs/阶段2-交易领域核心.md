# 阶段2：交易领域核心

## 范围

本阶段实现纯函数交易引擎，不接页面和数据库。输入为订单、当前已公开日线行情、账户和持仓快照；输出为拒单原因或新的账户、持仓和成交结果。

## 已实现规则

- 市价单使用当前已公开交易日收盘价。
- 买入滑点上浮、卖出滑点下浮，默认滑点为0。
- 买入必须是100股整数倍。
- 普通卖出必须是100股整数倍，剩余零股只能一次性全部卖出。
- 买入当日增加持仓但不增加可卖数量，推进到下一交易日后释放为可卖。
- 禁止透支、融券和做空。
- 停牌时禁止买卖；涨停禁止买入；跌停禁止卖出。
- 一期仅支持市价单，其他类型返回 `UNSUPPORTED_ORDER_TYPE`。
- 成交费用复用整数分手续费模块。
- 部分卖出按持仓比例分摊成本并计算已实现盈亏。
