# 阶段4：后复权导入与随机候选

## 数据工具

- Python 3.12解析通达信GBK、Tab分隔的日线后复权文件。
- 前两行分别作为股票元数据和表头，后续读取日期、OHLC、成交量和成交额。
- 金额和价格转换为整数分，标记 `adjustType=hfq`。
- 校验日期唯一递增、OHLC关系、非负量额和必需字段。
- 质量错误包含错误码、原始行号和交易日期，不静默跳过。
- 命令行支持单文件、目录、`--limit`小样本试运行和JSON质量报告。

## 市场分类

- `6xxxxx`：上证主板。
- `688xxx`：科创板。
- `0xxxxx`：深证主板。
- `3xxxxx`：创业板。
- `4xxxxx`、`8xxxxx`、`92xxxx`：北交所。
- 其他代码标记 `UNKNOWN`，不进入正式随机候选池。

## 随机候选

- 不按主板、创业板、科创板或北交所过滤，所有已知市场统一参与。
- 默认训练起点不得早于2021-01-01。
- 起点前必须有200根上下文，起点起必须有150或200根模拟日线。
- 使用固定seed的蓄水池抽样，避免把全量候选窗口一次性加载到内存。
- 相同数据、配置和seed必须选出相同股票及起点。
